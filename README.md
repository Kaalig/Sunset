# Sunset

Sunset est une application locale de "productivité" qui compile prise de notes, rendez-vous et tracker d'habitudes, avec un dashboard général pour voir le résumé de ces catégories. 

**Sunset** a pour objectif d'être un endroit ou l'on check rapidement ce que l'on doit faire dans la journée/semaine concernant les trois métriques ci-dessus. La vrai productivité c'est de ne jamais passer des heures sur une application de productivité.

## Installation
```bash
git clone https://github.com/Kaalig/Sunset.git
```

### Lancement

Double-cliquer sur `sunset.bat` — ça crée la base de données au premier lancement et ouvre l'app dans le navigateur. Ne pas supprimer le pop-up terminal de préférence.
